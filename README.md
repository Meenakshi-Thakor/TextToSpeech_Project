# 🗣️ Text-to-Speech App (Indian English Accent)

This project converts any English text into **Indian English accent speech (MP3)** using `gTTS` and a simple `Streamlit` web interface.

## 🚀 Deployment
The app is deployed on **Streamlit Cloud**.  
👉 [Click here to open the live demo](https://Meenakshi-Thakor-texttospeech.streamlit.app)

## 📌 Features
- Paste any text/paragraph
- Convert to natural sounding speech
- Listen online or download MP3
- Indian English accent (Google TTS)

## 🛠️ Tech Stack
- Python
- Streamlit
- gTTS (Google Text-to-Speech)
